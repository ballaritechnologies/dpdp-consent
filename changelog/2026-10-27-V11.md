## [Unreleased] - 2026-10-27
### Summary
Per-site rate limits for the public API. Each site counts a visitor IP separately, and an optional per-site cap stops one busy site from starving the others on a shared server.
### Added
- `rateLimit.maxRequestsPerSite` (`CONSENTI_RATE_LIMIT_MAX_REQUESTS_PER_SITE`): requests per window to one site from all IPs together. Unset means no cap.
- `rateLimit.siteLimits(tenantId)`: per-site overrides of `maxRequests` and `maxRequestsPerSite`.
- `RateLimiter.checkSiteRequest()`.
- Tests: per-site IP buckets and the per-site cap.
- Checked on MySQL 8.4: the schema v4 entity-records tests and a full server boot (consent for two sites, verified receipts). Postgres and MongoDB were re-run too.
### Changed
- `rateLimit.maxRequests` now counts per IP per site. Single-site servers are unchanged.
