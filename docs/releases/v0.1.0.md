# Ijazat v0.1.0

The first public release of Ijazat: open-source, DPDP-first consent tooling built on
[Consenti](https://github.com/santoshe61/consenti).

> Ijazat helps you meet DPDP and GDPR consent requirements; it does not make a site lawful by
> itself, and nothing in it is legal advice. Built-in notice texts are labelled
> `DRAFT - REQUIRES LEGAL REVIEW`.

## Highlights

- **DPDP consent flow:** itemised notice, one choice per purpose, nothing pre-ticked, reject as
  easy as accept, Data Fiduciary and grievance contact, persistent "Privacy choices" button for
  withdrawal, and English, Hindi, Kannada, Telugu and Tamil.
- **Per-site regimes:** `dpdp` and `dpdp_gdpr` (India → DPDP, EU/EEA/UK → GDPR, others → your
  default).
- **DPDP consent checker:** `consenti-scanner dpdp <url>` writes a JSON + HTML gap report, entirely
  on your machine.
- **Docker quickstart** built from source.

## Upgrading from Consenti

Ijazat keeps Consenti's package names, configuration and data formats. SQL databases move to schema
v4 automatically on start (one added column and one added table, `entity_records`). See `changelog/` for every change.

## Known limitations

- The bundled documentation site (`apps/docs`) is still largely upstream's and will be rebranded.
- Indian-language texts await native-speaker and legal review (`docs/legal-open-questions.md`).
- The product name awaits trademark clearance (`docs/naming.md`).
