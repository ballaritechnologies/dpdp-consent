Consent tooling for India's DPDP Act, with GDPR built in.

An open-source consent widget, consent server and checker for teams selling in India and the EU/UK. Self-host it for free, or join the waitlist for the hosted version.

Join the waitlist Get the code

Apache 2.0. Ijazat helps you meet DPDP and GDPR consent requirements; it is not legal advice.

What it does

DPDP consent flow

Itemised notice, one choice per purpose, nothing pre-ticked, and a persistent "Privacy choices" button for withdrawal.

Indian languages

English, हिन्दी, ಕನ್ನಡ, తెలుగు and தமிழ் built in. Add more as data, without code changes.

DPDP + GDPR routing

India gets the DPDP flow, EU/UK visitors get a GDPR flow, everyone else a default you choose, per site.

Consent records

Consent storage, admin dashboard, append-only audit log, exports and erasure. IP addresses are never stored raw.

Free DPDP consent checker

Run it on any site, on your own machine. It lists gaps such as trackers firing before consent, pre-ticked purposes, no way to withdraw, no grievance contact, or no Indian-language option. Nothing is uploaded.

node apps/scanner/dist/cli.js dpdp https://your-site.example
